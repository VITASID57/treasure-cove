# 百宝湾 · Treasure Cove

给“小机子”们准备的插件与小工具合集。大家把自己做的、或者觉得好用的东西冲上岸，路过的人捡走就能用。

- **不是任何产品的官方渠道。** 百宝湾由社区维护，收录的作品各自归作者所有、由作者维护。
- **目前主要面向棉棉云小镇。** 小镇只提供能接入的接口，不推荐、不审核这里的作品；装什么由你自己决定。
- **浏览页：** 开通后见仓库右侧的 Pages 地址。

## 能找到什么

| 类型 | 怎么用 |
|---|---|
| 小镇插件包 | 下载 `.mimi-app.json`，在小镇「插件中心 → 添加插件 → 从文件安装」 |
| 远程 MCP | 复制地址，在小镇「插件中心 → 连接工具（MCP）」粘贴 |
| 网页小玩意 | 打开网址就能玩 |
| 需要自己部署 | 按作品说明部署到自己的服务器，再接入 |
| 适配包 | 别人的作品原样不动，另做一个让它能接进小镇的小包；卡片上分开写原作者和适配者 |

## 深水区

成人向作品放在“深水区”。浏览页默认不显示，确认已成年后才能下水。

## 规矩

所有作品都必须做到：

1. 不涉及未成年人；不涉及真实存在的人。
2. 仓库里不放露骨的文字和预览图。成人向作品只做“工具”，内容由使用者自己的模型生成。
3. 转载写明原作者、来源和许可；原作没写许可的，只放链接，不打包原作代码。
4. 不收集使用者的密钥、聊天或私人资料；需要联网的，要在说明里写清楚连到哪里、传出什么。
5. 不放付款、打赏链接。

违反规矩的作品会被下架。

## 投稿

- **会用 GitHub：** 在 `entries/` 下新建一个文件夹，放一份 `entry.json`（格式见 [作品说明格式](docs/entry-format.md)），然后提 PR。
- **不会用 GitHub：** 在 Issues 里选「投稿」，按表单填写，维护者会帮你整理上架。

维护者合并以后作品才会出现在浏览页上。检查程序会自动核对格式、去重、计算插件包的指纹。

## 自己检查

```bash
node scripts/build-index.mjs
```

会在 `site/index.json` 生成索引。加上 `--verify-remote` 还会下载远程插件包，核对指纹。

## 许可

本仓库的脚本和浏览页使用 MIT 许可。收录的每件作品沿用它自己的许可，以作品说明里写的为准。
